# 🔗 MinuteLink – URL Shortener

MinuteLink is a simple and efficient URL Shortener web application that converts long URLs into short, easy-to-share links.

The project provides a convenient way to create shortened URLs and redirect users to the original destination using the generated short link.

---

## 🚀 Features

- 🔗 Shorten long URLs into compact links
- ⚡ Fast URL redirection
- 📋 Easy-to-share shortened URLs
- 🗄️ Store and manage shortened URLs
- 🌐 User-friendly web interface
- 🔒 Secure backend API
- 📱 Responsive design
